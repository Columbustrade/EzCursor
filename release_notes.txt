✦ Mới trong 1.6.0: Hồ sơ riêng cho từng game
- Mỗi game có thể có con trỏ, màu, kích thước, ảnh và hiệu ứng riêng; EzCursor tự đổi khi bạn chuyển game
- Tạo hồ sơ: tab Ứng dụng → bấm "+ Hồ sơ riêng" ở dòng của game
- Chọn hồ sơ cần chỉnh bằng ô "Đang chỉnh" ở đầu các tab Con trỏ, Bộ sưu tập, Hiệu ứng
- Game chưa có hồ sơ riêng dùng kiểu Mặc định như trước; phím tắt đổi hình/đổi màu áp dụng cho hồ sơ của game đang chơi

✦ New in 1.6.0: Per-game profiles
- Each game can have its own cursor, color, size, image and effects; EzCursor switches automatically
- Create one in the Apps tab with "+ Own profile" on the game's row
- Pick the profile to edit with the "Editing" box at the top of the Cursor, Library and Effects tabs
- Games without a profile keep using the Default style; shape/color hotkeys change the profile of the game you're playing
