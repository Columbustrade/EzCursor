- Sắp xếp lại mã nguồn EzCursor thành nhiều phần nhỏ, dễ bảo trì và cập nhật hơn. Tính năng và cách dùng giữ nguyên như 2.2.0

✦ New in 2.2.1
- Fixed a 2.2.0 bug: the EzCursor cursor was hidden behind the taskbar

- Added automated tests: on every source update, GitHub checks the interface, cursor sets and how smoothly the cursor follows the mouse
